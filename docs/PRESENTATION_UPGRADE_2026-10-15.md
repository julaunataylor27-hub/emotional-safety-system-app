# Presentation upgrade for 27 October 2026

Version 1.7.0 / Android version code 18. Prepared for Julauna Taylor.

The visual direction is a calm forest-and-champagne palette, natural scenic artwork, consistent native line icons, generous spacing and readable typography. It expresses healthy growth and shared humanity while clearly identifying the app as a prototype.

## What changed

- Home: a new eucalyptus scene, clean primary button, clearer text and entry points to the presentation overview and preferences.
- All inner screens: shared colours and typography, clearer headings, larger body text, quieter cards, consistent icons and native navigation. Decorative dots, a nonfunctional header ornament and competing logo treatments were removed from the visible shell.
- Journey: coherent scenic cards, easier reading and preserved local writing/PDF controls. Literal backslash-n text in old banner titles is converted to an actual line break.
- Learning: the topic search now filters public learning material on the device. About's Evidence & Research link opens the intended example tool.
- Preferences: saved language, country, standard/larger reading size, reduced motion and an optional future-language preference. Saving failures preserve the draft; loading failures prevent replacement of unread preferences.
- Inclusion: English, Spanish, French and Indonesian navigation dictionaries. The interface states that reflections, cultural content, support and legal information remain in English. These starter translations require speaker review before broader use.
- International support: visitors outside Australia see an honest local-support scope message rather than Australian dialler buttons presented as local contacts. The question form offers Western Australia, Elsewhere and Unsure; a non-Australian preference clears the default WA selection. Country preference never certifies where an event happened.
- Presentation overview: purpose, current methods, fictional examples, cultural scope, present capabilities and a staged pathway to an evaluated pilot and community-led expansion. No claims of proven wellbeing improvements or parliamentary endorsement.

## A short demonstration

1. Start at Home and open Our Purpose & Vision. Introduce the purpose in your own words.
2. Open a fictional example. Explain how reported events, feelings, possible interpretations and unknowns stay distinct.
3. Return Home and open Knowledge. Show its definition, the Noongar connection and public source links.
4. Open the Journey. Use clearly fictional demonstration writing if you show a form; keep private reflections off a shared display.
5. Show Language & Reading Preferences. Explain what is translated now and what would need community and local review.
6. End with the overview's question: what would make the project more useful, culturally respectful and accessible?

Use the newly installed APK to rehearse before the meeting. Updating repository code does not update an existing installation. Keep a separate copy of important writing before updating or uninstalling; app storage is local and unencrypted.
