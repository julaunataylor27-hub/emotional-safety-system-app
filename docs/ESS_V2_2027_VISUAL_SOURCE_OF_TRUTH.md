# ESS v2 — 2027 Visual Source of Truth

Status: **LOCKED DESIGN REFERENCE**

The approved 2027 system frame is now the visual source of truth for ESS v2.

## What this means

Every new v2 screen must be designed against the approved frame before it is considered ready.

If a screen begins to resemble the retired v1 product, the screen is considered off-direction.

## Visual direction

ESS v2 should feel like:

- a premium 2027 Australian product
- cinematic and grounded rather than futuristic or abstract
- warm, human and calm
- realistic mobile UI rather than concept-dashboard graphics
- visually connected to Country without turning cultural symbolism into decoration
- spacious, readable and deliberate

## Colour system

Use the new earth palette:

- Warm charcoal — primary background
- Sandstone — primary actions / active navigation
- Eucalyptus — evidence, transparency and calm informational states
- Clay / rust — emotional emphasis
- Ochre — secondary earth accent
- Soft cream — primary text
- Muted earth — secondary text

The retired navy / gold / teal identity must not return.

## Core app structure

Persistent navigation:

1. Home
2. Journal
3. Learn
4. Support
5. More

## Screen rules

### Home
- cinematic Australian landscape hero
- calm welcome / orientation
- one clear primary reflection action
- compact entry points to understanding, learning, support and transparency
- no giant stacked dashboard blocks

### Journal
- private reflection space
- recent entries
- calm progress context
- no scoring or gamification pressure

### Learn
- compact visual learning trails
- strong source / context hierarchy
- culture, history, evidence, emotional wellbeing, rights and systems
- no oversized generic cards

### Support
- calm by default
- urgent styling only when genuinely needed
- trusted human support and options
- no permanent red emergency strip

### More
- About ESS
- Settings
- Research & development
- Transparency
- Help / feedback

## Underlying system

The rigorous layer stays visually quieter than the user experience:

- Language interpretation
- ESS rules engine
- Uncertainty tracking
- Safety routing
- Choice preservation
- Version / rule logging

Foundation:

- Privacy
- Evidence discipline
- Cultural integrity
- Accessibility
- Continuous improvement

## Design principle

**Human on the surface. Rigorous underneath.**

## Acceptance test

A v2 screen is only visually accepted when:

1. it looks like it belongs in the approved 2027 frame,
2. it uses the earth palette,
3. it uses the five-tab structure,
4. it does not depend on v1 layout components,
5. it avoids sci-fi / orbit / dashboard motifs,
6. it keeps information hierarchy calm and clear,
7. the visual design supports rather than competes with ESS Core,
8. urgent styling appears only when context requires it.
