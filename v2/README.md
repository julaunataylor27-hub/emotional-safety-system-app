# ESS v2 — Clean Rebuild

This folder is a new application, not a visual patch of v1.

## Rules

- Do not import v1 screen layouts.
- Do not run v1 UI patch scripts against v2.
- Migrate only proven logic, content and tests.
- Build new UI components from one v2 design system.
- Keep the principle: **Human on the surface. Rigorous underneath.**
- Preserve user choice and explicit uncertainty.

- ESS Core
- Evidence & Truth engine
- Testable architecture / rule logging
