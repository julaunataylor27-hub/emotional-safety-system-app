# Tim Berners-Lee photograph

`tim-berners-lee-2014.jpg` is Paul Clarke’s photograph, taken 24 September 2014, reproduced without image edits. It is scaled with its original aspect ratio in the app.

- Source: https://commons.wikimedia.org/wiki/File:Sir_Tim_Berners-Lee.jpg
- Original file: https://upload.wikimedia.org/wikipedia/commons/9/9d/Sir_Tim_Berners-Lee.jpg
- Licence: Creative Commons Attribution-ShareAlike 4.0, https://creativecommons.org/licenses/by-sa/4.0/

The app displays the photographer, year, licence and a link to the original record. Inclusion does not imply endorsement. The five-step Knowledge Trail is an app-created framework, rather than a method attributed to Berners-Lee.
